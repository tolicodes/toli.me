# Toli’s little worlds — icon sheet v1

Created October 3, 2026 with built-in ImageGen as a standalone visual exploration requested by Toli. This does not replace or deploy the current beta artwork.

- [Full icon sheet](toli-icons-v1.png): 54 numbered icons in a six-column, nine-row grid, 1024 × 1536 PNG.
- [Complete item index](toli-icons-v1-index.json): maps every sheet number to the original inventory ID, title and category.
- [Exact prompt and references](toli-icons-v1-prompt.json): source files and generation provenance.

The proposed style is flatter, with consistent forest-ink outlines, simple color blocks and warm ivory paper. There are no roads, city details or scenery. The four current editorial favorites (03, 05, 15, 19) receive a gold star. Pickle Rick, the living green book, the apple/code braces and Dota Invoker retain their recognizable identities.

Distinct catalogue entries stay distinct even where they share a subject: the two neurodiverse guide placements, LeetCode community/podcast, dog/dogsitting, parody/obscure parody, and two DALL-E collections. All 54 captions and subjects were visually checked against the inventory. Some labels are shortened; the index preserves original titles. Character variations, surreal objects and category emblems are creative proposals, not assertions of official project branding. User selection or revision is still open.
