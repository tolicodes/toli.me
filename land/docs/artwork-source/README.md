# Artwork sources

These 13 illustrations were generated for Toli Land with the built-in OpenAI imagegen tool, using the selected Toli Land concepts as visual references. They share a sunny gouache storybook style, blue water, planted islands, and literal objects that represent the site's content. They are generated illustrations rather than documentary photographs.

Every final source PNG is **1536 × 1024 pixels**. The original PNG bytes are preserved here under `maps/` and `projects/`. Matching WebP derivatives are served from `public/assets/`; keeping the source PNGs outside `public/` prevents duplicate originals from being copied into the production bundle. Map illustrations include landscape signs. Project hero illustrations leave titles and controls to the application.
